# 📦 API de Produtos – CRUD em Java

Este projeto é uma **API RESTful** desenvolvida em **Java** para gerenciamento de produtos, permitindo realizar operações de **CRUD** (Create, Read, Update e Delete).

---

## 🚀 Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- Maven
- Banco de Dados (H2)
- Swagger (OpenAPI)

---

## 📌 Funcionalidades

- ✅ Cadastrar produto
- 📄 Listar todos os produtos
- 🔍 Buscar produto por ID
- ✏️ Atualizar produto
- ❌ Deletar produto

---
